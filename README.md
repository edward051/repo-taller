## Descripción del proyecto

Este repositorio contiene la evidencia práctica de un taller sobre control de versiones con Git y GitHub. Se trabajó con un repositorio local y remoto, se creó la rama `prod` a partir de `main`, se realizaron y registraron cambios en ella, y se subió al repositorio remoto en GitHub.

Posteriormente se generó un Pull Request desde `prod` hacia `main`, provocando intencionalmente un conflicto entre ambas ramas para practicar su identificación y resolución. Una vez resuelto el conflicto, se completó el proceso de integración mediante el merge del Pull Request, dejando en el historial de commits la evidencia completa del proceso realizado.
